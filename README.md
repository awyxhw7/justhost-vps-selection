## 配置：1核1G、1核2G、2核2G 分别能干什么

RackNerd 的测评作者给过一个判断：普通 B2B 外贸独立站，1 核 2G 起步完全够用，WordPress 本身不重，重的是主题和插件。DMIT 那边的说法是，1G 内存跑轻量 WordPress 配 Nginx 加缓存插件基本够用，装了很多插件或同时跑多个站再上 2G。

按这个尺度对到 JustHost：

**1 核 1GB（Sirius）** 适合产品页在 100 个以内、装了缓存插件、日访问几百到两千 PV 的展示站。20GB NVMe 放几百张压缩过的产品图没问题。这套配置的天花板在内存，不在 CPU——插件一多、后台一开多标签，MySQL 容易吃满内存。

**1 核 2GB（Arcturus）** 是多数人的舒适区。多出来的 1GB 内存让 Elementor 这类可视化编辑器、多语言插件、询盘表单能同时跑起来，不用天天盯着内存告警。

**2 核 2GB（Alpha Centauri）** 多一个核心，主要改善并发。客户同时打开产品页、你自己在后台改内容，两边不打架。带宽也从 300Mbps 提到 400Mbps。

要到 2 核 4GB 以上，通常是三种情况：跑 WooCommerce 真正在收单、一台机放两个以上站点、或者产品视频直接放服务器上。

## 下单前必须确认的六件事

**1. 备份要自己搭。** JustHost 官网 FAQ 写得很直接：不提供自动备份，建议用户自建备份服务器，把副本存到另一台独立服务器上。这条对外贸站是硬伤——询盘记录、客户跟进数据、产品图全在里面。开站第一周就把定时备份脚本或面板备份跑起来，异地存一份。别指望快照功能，切换机房时连服务器本身都会被重建。

**2. 流量不限，但端口共享。** 所有标准套餐标的是不限流量、端口公平共享（300Mbps 约等于每月 93TB 以上），正常外贸站根本跑不到。但如果你的站要托管视频、或者被爬虫盯上，长期占满端口会被限速。带宽可以加钱买：+10Mbps 是 ¥16.80/月，独享 1Gbps 是 ¥2240.85/月——后者明显不是给中小站准备的。

**3. 邮件端口。** 只有 VPS Promo 封了 25/465/587。标准套餐没这个限制，但独立站发订单确认、询盘通知，还是建议走 SendGrid、Mailgun 这类专业发信服务，服务器 IP 直接发信进垃圾箱的概率不低。

**4. 支付方式。** JustHost 支持支付宝，对国内卖家省了信用卡环节。结账前确认币种，人民币标价和美元标价会随汇率浮动。

**5. 工单语言与响应。** 官方写的是 24/7 技术支持、真人客服。实际沟通语言和平均首次响应时间，公开页面没给具体承诺，第一次开单时自己感受一下。完全不想碰英文的，得提前想好翻译方案。
